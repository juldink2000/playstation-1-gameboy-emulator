# playstation-1-gameboy-emulator
This is a Game Boy emulator for the PlayStation 1. It is still in early development. There is currently no sound, and I haven't been able to get it running above 20 FPS or achieve a stable frame rate yet.  You can burn it to a CD-R and run it on a real PlayStation 1.  If you want to add a new game, read the README for the rest of the instructions.
